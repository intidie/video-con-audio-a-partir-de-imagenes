# Fuentes para los subtítulos

La app lista automáticamente las fuentes de esta carpeta (y las instaladas en el sistema). Para usar otra,
copia su `.ttf` / `.otf` aquí y reinicia la app (o elige «Otra (escribir el nombre)» si ya está instalada).
